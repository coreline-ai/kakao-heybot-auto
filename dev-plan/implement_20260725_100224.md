> **문서 상태: 활성/E2E 잔여.** 중앙 관리자와 전역 일반대화 코드는
> 구현됐다. 남은 범위는 control room exact 권한, 재시작 OFF, 다른 방 거부,
> 기존 호출어·이미지 무회귀와 일반대화 단독 롤백 검증이다. 일반대화의
> 실제 방 범위·응답 안전·자동 정지는 후속 `102332` 정책이 우선한다.

이 문서는 코어라인 AI 연구소를 헤이봇의 유일한 관리자 제어 방으로 고정하고, 그 방의 정확한 관리자 `userId`가 모든 허용 방의 일반대화 모드를 전역으로 시작·상태 확인·종료할 수 있게 하는 작업 문서다.

## 개발 목적

관리자 권한을 닉네임이 아닌 Kakao 숫자 `userId` exact match로 부여한다. 관리자 설정·운영 상태·전체 기억 관리·일반대화 전역 제어는 오직 코어라인 AI 연구소(`chatId=18480337854645134`)에서만 실행되게 한다.

지정 관리자가 코어라인 AI 연구소에서 `헤이봇 대화 시작`을 보내면,
`IRIS_GENERAL_CONVERSATION_ALLOWED_CHAT_IDS`에 명시한 방에서만 호출어 없는 일반대화
후보를 처리한다. 이 값은 GLM 허용방의 부분집합이어야 한다. `헤이봇 대화 종료`는
모든 일반대화 허용방에서 즉시 중단한다.

## 개발 범위

- root 전용 관리자 ID 파일에 지정 관리자의 실제 숫자 `userId` 등록
- `IRIS_BOT_ADMIN_CONTROL_CHAT_ID`의 단일 control-room 설정과 strict validation
- 기존 관리자 명령 전체를 control room + exact admin userId 조합으로 제한
- `헤이봇 대화 시작/상태/종료` 관리자 전용 전역 명령
- process-local 전역 일반대화 mode state와 기본 OFF·재기동 OFF 정책
- 명시적 일반대화 allowlist 대상의 `REPLY/WAIT/IGNORE` arbitration, queue·rate limit·봇 에코 보호
- JVM 회귀 테스트, release APK build, 승인 후 PD20 관리자 파일 적용·제한 E2E·롤백 문서

## Phase 2. 전역 일반대화 제어와 arbitration

### 목표

코어라인 AI 연구소 관리자의 전역 start/stop이 모든 허용방의 호출어 없는 일반대화 참여 여부를 안전하게 제어한다.

### 구현 태스크

- [x] `BotCommandRouter`에 `대화 시작/상태/종료` local command를 추가한다.
- [x] `GeneralConversationModeStore`를 구현한다. start/stop/status/close만 책임지고 restart 복원은 하지 않는다.
- [x] `GeneralConversationArbiter`에 strict JSON prompt·parser를 구현한다.
- [x] `GlmAutoReplyHandler`가 command를 우선 실행하고, mode ON일 때만 무호출어 메시지를 일반대화 request로 queue에 등록하게 한다.
- [x] 일반대화 request는 기존 room FIFO, global concurrency, duplicate·room/user rate limit을 공유한다.
- [x] reply send 성공 때만 metric을 기록하고, WAIT/IGNORE/error/invalid은 발신하지 않는다.
- [x] status/settings에 전역 mode 상태만 노출하고 사용자별 대화 원문·세션을 노출하지 않는다.

### 자체 테스트

- [x] start 전에는 모든 허용방의 무호출어 입력이 GLM 0회다.
- [x] control room start 뒤 두 개 허용방의 질문이 arbitration으로 처리된다.
- [x] stop 뒤에는 모든 허용방의 무호출어 입력이 GLM 0회다.
- [x] WAIT/IGNORE/invalid JSON/error는 카카오 reply 0건이다.
- [x] 호출어 질문·이미지·관리 명령이 일반대화 arbitration보다 우선한다.
- [x] 한 방의 느린 일반대화가 다른 방 및 control-room 로컬 명령을 막지 않는다.
