## 개발 목적

여러 계획에 중복으로 남은 체크박스를 독립 개발 backlog로 오인하지 않게 정리한다.
자동화 가능한 ADB reverse·watchdog 복구 경로는 fake ADB 회귀 테스트로 고정하고,
남는 작업을 외부 카카오 E2E와 장시간 운영 검증으로 명확히 분리한다.

## 개발 범위

- `dev-plan/README.md` 기준의 단일 잔여 작업 순서 확정
- watchdog script의 의존 명령 주입 지점과 fake ADB 회귀 테스트
- reverse 누락·ADB 미연결·readiness 연속 실패·복구의 자동 검증
- 기존 Android·Node 서버 회귀 테스트와 launchd readiness 재검증
- 외부 비봇 카카오 계정이 필요한 E2E의 실행 순서·성공 기준 기록
