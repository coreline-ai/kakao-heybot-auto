# implement_20260726_141425.md

작성 일시: `2026-07-26 14:14:25 KST`

이 문서는 Iris Android 패키지 식별자를 `party.qwer.iris`에서 `ai.coreline.heybot`으로 완전히 변경하고, 기존 PD20 운영 배포가 새 진입점으로만 실행되도록 하는 범위를 고정한다.

## 개발 목적

현재 Iris Android 소스와 namespace는 `party.qwer.iris`를 사용한다. 이를 코어라인 헤이봇 제품 식별자에 맞춘 다음 패키지로 변경한다.

```text
기존: party.qwer.iris
신규: ai.coreline.heybot
```

변경 후에도 카카오톡 DB 연동, GLM/Codex/Grok 대화 엔진, 이미지·영상·펜브러쉬 프록시, 관리자·방 정책, PD20 ADB reverse 운영을 동일하게 유지한다.

## 개발 범위

- Android `namespace`와 명시적 `applicationId`를 `ai.coreline.heybot`으로 변경
- `app/src/main` 및 `app/src/test`의 Kotlin package 디렉터리·선언·import 전체 이동
- `Main` app_process 진입점과 모든 reflection/class-name 참조를 새 패키지로 변경
- Android manifest, Gradle, ProGuard/R8, generated source 및 테스트의 패키지 참조 정리
- APK 산출·배포 스크립트와 PD20 `app_process` 실행 명령을 새 진입점으로 변경
- 기존 `/data/local/private`의 토큰·관리자·방 정책·대화 기억·엔진 모드 파일은 보존
- old/new package 잔존 문자열 정적 검사와 Android JVM test/release build 수행
- PD20 재배포 후 새 Main 기동, CODEX 모드·ADB reverse·프록시 readiness를 확인
- 개발 계획 인덱스와 Iris 운영 문서의 패키지·배포 설명 갱신
- vendor 디렉터리 이름을 `vendor/Iris`에서 `vendor/android`로 변경하고 Gradle·스크립트·문서 경로 참조를 갱신

## 제외 범위

- 카카오톡 앱 패키지(`com.kakao.talk`) 또는 카카오톡 DB 스키마 변경
- proxy-manager, proxy-conversation, proxy-codex, proxy-grok 등 서버 패키지 ID 변경
- `/data/local/private` 파일 경로와 secret 값의 재발급·초기화
- GLM/Codex/Grok 프롬프트, 대화 정책, room capability, 관리자 권한 의미 변경
- 새로운 Android 기능·의존성·UI 추가
- old package를 확인하지 않고 `pm uninstall`하거나 카카오톡 데이터를 삭제하는 작업

## 잔여 리스크 / 후속 과제

- 기존 APK가 Android package manager에 설치되어 있으면 old/new identity가 동시에 보일 수 있으므로 실제 package 목록을 확인한 뒤 정리한다.

- 외부 카카오 계정의 실제 메시지 전송은 package rename 자동 테스트와 분리해 제한 E2E로 확인한다.
