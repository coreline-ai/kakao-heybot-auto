## 개발 목적

Iris 기반 헤이봇이 Mac의 `proxy-manager` 단일 진입점을 통해 `proxy-image`에 작업을 요청하고, `proxy-image`가 공용 `proxy-codex` 내부 API로 Codex CLI 작업을 실행해 검증한 PNG를 PD20으로 내려받아 카카오톡 방에 직접 이미지로 전송하도록 구현한다.

## 개발 범위

- `new-bot/vendor/server/proxy-manager` 독립 Node.js/TypeScript 관리자·gateway 패키지
- `new-bot/vendor/server/proxy-image` 독립 Node.js/TypeScript 이미지 프록시 패키지
- `new-bot/vendor/server/proxy-codex` 독립 Node.js/TypeScript 공용 Codex 실행 패키지
- Codex CLI capability 검증·전역 queue·격리 worker
- 비동기 image job API
- 프록시별 독립 OS process와 launchd service
- durable domain queue와 engine queue
- 설정 가능한 concurrency·전체 pending·방별 pending 한도
- 직렬 생성, idempotency, timeout, cancel
- PNG 검증과 실제 픽셀 QC
- 인증된 이미지 다운로드
- PD20 ADB reverse
- registry 기반 기능별 proxy 분기
- proxy별 health·readiness·contract test와 장애 격리
- 기능 프록시가 호출하는 caller/capability 기반 Codex 내부 Job API
- Iris 이미지 명령, polling, byte 다운로드, 이미지 전송
- health, readiness, self-test
- Mac foreground 운영 후 launchd 운영
