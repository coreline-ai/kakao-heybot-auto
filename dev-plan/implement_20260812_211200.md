# implement_20260812_211200.md

작성 일시: `2026-08-12 21:12:00 KST`

이 문서는 이미지 분석이 “분석 가능한 이미지를 찾지 못했다”로 끝나는 원인을
정적 허용 목록·발신자 고정 탐색에서 제거하고, 방 capability 정책을 단일한
실행 기준으로 만드는 작업 범위를 고정한다.

## 개발 목적

- 동일 방에 있는 최근 이미지를 분석할 때 이미지 발신자와 명령 사용자가 달라도
  안전하게 선택할 수 있게 한다.
- `IRIS_VISION_ALLOWED_CHAT_IDS` 정적 목록과 동적 방 capability 정책의 이중
  권한 판단을 제거한다.
- 이미지 분석이 불허용이거나 분석 대상이 없을 때 프록시 장애처럼 보이지 않도록
  원인을 구분해 안내·요청 추적에 남긴다.

## 개발 범위

- 이미지 분석 명령의 방 허용 판단을 `RoomCapability.IMAGE_ANALYSIS` 정책만으로
  수행한다.
- 정책에 등록된 방에서만 명령을 분류한다. 정책에 없는 방은 기존처럼 조용히
  fail-closed하며 자동 등록하거나 권한을 부여하지 않는다.
- 답장이 아닌 명령은 같은 방에서 최근 30분 내 수신한 가장 최신의 분석 가능
  이미지 1장을 발신자와 무관하게 선택한다.
- 정확한 이미지 답장은 기존 `threadId/src_logId` 기반 선택을 유지한다.
- 방 불허용, 정확한 답장 대상 없음, 최근 이미지 없음에 대한 안정된 trace code와
  사용자 안내를 추가한다.
- Android 도움말·운영 문서·PD20 기동 스크립트에서 정적 vision allowlist 설명과
  환경값을 제거한다.

## 제외 범위

- 정책에 없는 카카오톡 방을 자동으로 지원 방에 추가하거나 권한을 자동 허용하는 기능
- 다른 방의 이미지, 만료 CDN URL, 지원하지 않는 첨부 형식의 분석
- 이미지 분석 프록시·Vision 모델·원본 다운로드 보안 계약 변경
- 사용자 명시 없는 카카오톡 이미지 전송 또는 실제 분석 canary

## 확인·결정 기록

| 항목 | 결정 |
| --- | --- |
| 실제 DB 관찰 | 최근 `type 2/3` 이미지 첨부 행은 존재했다. 그러나 일부는 정책 미등록 방, 일부는 이미지분석 불허용 방 또는 30분 범위 밖이었다. |
| 단일 권한 기준 | 런타임 `RoomCapabilityPolicyStore`만 권한 기준으로 사용한다. 배포 스크립트의 정적 `IRIS_VISION_ALLOWED_CHAT_IDS`는 제거한다. |
| 최근 이미지 공유 범위 | 같은 `chatId` 안에서만, 설정된 recent window와 CDN 만료·형식 검증을 통과한 최신 1장만 선택한다. |
| 미등록 방 | 정책에 없는 방은 자동 허용하지 않고 명령도 분류하지 않는다. 관리방에서 정책에 등록하는 별도 작업이 필요하다. |
| 불허용 관리 방 | 정책에는 등록됐지만 이미지분석이 OFF인 방은 명시 명령에 한해 기능 불허용 안내를 보낸다. Vision 프록시는 호출하지 않는다. |
