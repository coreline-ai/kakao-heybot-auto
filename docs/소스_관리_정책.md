# new-bot 소스 관리 정책

작성 기준: `2026-07-25 KST`

- 서버·문서·운영 스크립트 Git 저장소 루트는 `/Volumes/Eprojects/project_202607/kakao-new-bot/new-bot`으로 한다.
- `old-bot`은 별도 저장소이자 라이선스상 분석 참조 전용이므로 포함하지 않는다.
- `vendor/android`는 현재 동작하는 Android 소스 스냅샷을 루트 `main` 저장소에서 함께 관리한다.
- 기존 Iris upstream 이력은 기준 커밋으로 추적하며 `vendor/android/.git` 같은 중첩 Git 메타데이터는 커밋하지 않는다.
- Iris GLM·P1·이미지 연동 기준 커밋은 `feature/glm-autoreply`의 `8be4aad`다.
- 서버·문서·운영 스크립트의 최초 현재 구현 기준 커밋은 `main`의 `fd52454`다.
- `vendor/server`의 TypeScript 소스, lockfile, 설정 example, 문서는 버전 관리한다.
- API key, route/internal/admin secret, Codex 인증, runtime DB, artifact, log, APK와 build 결과는 커밋하지 않는다.
- 서버·Android·문서·운영 스크립트는 외부 저장소의 `main` 브랜치에 함께 커밋한다.
- 구현 이전 `new-bot` 전체 기준 커밋은 존재하지 않는다. Iris 원본 복원은 upstream 이력, 현재 구현 복원은 위 기준 커밋을 사용한다.
